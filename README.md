# Teams Phone Block Manager

Manage Microsoft Teams tenant-wide blocked
phone numbers through a web interface.

## Features

- View blocked numbers
- Add blocked numbers
- Remove blocked numbers
- Teams PowerShell integration
- Entra App authentication
- Settings page
- IIS deployment

## Requirements

- Windows Server / IIS
- PowerShell 7
- MicrosoftTeams PowerShell Module
- .NET 8 Hosting Bundle
- Entra App Registration
